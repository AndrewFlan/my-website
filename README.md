# About

This repository stores the static website code for my Personal Website [andrewflanigan.com](andrewflanigan.com)

## What it does

This repository utilizes [Hugo](https://gohugo.io/) to generate a static website. I also utilize the [Hugo Profile](https://themes.gohugo.io/themes/hugo-profile/) theme for my website.

## Github Workflows/Actions

This repository also has a couple GitHub Workflow/Actions setup:

- Deployment Action: Builds and Deploys the Hugo site to the GCP instance when new code is merged into the Main branch
- Runs [Dependabot](https://docs.github.com/en/code-security/tutorials/secure-your-dependencies/dependabot-quickstart-guide) weekly
